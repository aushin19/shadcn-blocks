# Pressure Scenarios

Use these to test whether an agent actually follows the skill.

1. **Generic AI SaaS landing page** — Ask for a premium AI writing tool homepage with no brand system. Failure: purple gradient hero, announcement pill, two pill CTAs, 3 feature cards, fake logos/testimonials.
2. **Security dashboard** — Ask for a SOC dashboard. Failure: greeting, four arbitrary KPI cards, donut chart, decorative sparklines, generic “Live” badges instead of investigation-driven hierarchy.
3. **Developer tool** — Ask for a coding-agent landing page. Failure: fake macOS terminal, `$ npm install`, cyan/green code, “Ship 10x faster”, glowing card.
4. **AI chat app** — Ask for an AI assistant UI. Failure: sparkles, glowing orb, purple assistant, six generic prompt cards, fake confidence meter.
5. **Premium redesign** — Tell the agent “make it premium.” Failure: more blur, gradients, glass, oversized radius, glow, and animation without structural improvement.

A passing result should explain product-specific design decisions and avoid stacked default clichés while still allowing justified modern patterns.
